# OCR ภาษาไทย

บันทึกเมื่อ 2026-11-01 ตัวเลขขนาดและความแม่นยำมาจากหน้าของผู้สร้างโมเดล ส่วนผลทดสอบเป็นของเราเอง

## ตอนนี้ทำได้แค่ไหน

Scan & OCR อ่านไทยและอังกฤษได้ในเครื่อง ไม่ส่งไฟล์ออกไปไหน ใช้ได้ทั้ง Mac, Windows และ Ubuntu เพราะรันผ่าน `rten` ซึ่งเป็น Rust ล้วน ได้ PDF ที่ค้นหาและคัดลอกข้อความไทยได้ ภาพหน้าเดิมไม่เปลี่ยน

- **ตัวตรวจบรรทัด:** `text-detection.onnx` ของ `ocrs` ตัวเดิม
- **ตัวอ่าน:** PaddleOCR PP-OCRv5 Thai mobile (`thai-recognition.onnx`) 7.9 MB ใบอนุญาต Apache-2.0 แปลงเป็น ONNX โดย RapidAI
- **พจนานุกรม:** `ppocrv5_th_dict.txt` จาก PaddleOCR v3.2.0 ในไฟล์นี้ `ω` กับ `ก` ติดกันอยู่บรรทัดเดียว (พลาดจากต้นฉบับ) ส่วนรายการในตัวโมเดลแยกกัน `ppocr.rs` จึงแยกให้
- **ชั้นข้อความ:** ฟอนต์ Type 0 ที่มี glyph ว่าง (`crates/engine/src/ocr/layer.rs`) เพราะ PDFKit ของ Apple มองไม่เห็นข้อความใน Type 3 ว่าง

## ผลทดสอบกับใบประกาศจริง (ภาพ 300 dpi)

เวลาทั้งหมดราว 2.5 วินาทีบน Mac ขนาดตัวอักษรกลางอ่านถูก เช่น หัวเรื่อง วันที่ สถานที่ ชื่อ และตำแหน่ง ที่ผิดคือ `บางขุนเทียน` ออกมาเป็น `บามางบุนเทียน` เพราะตัวตรวจบรรทัดแบ่งคำตรงกลางคำนั้น และมีตัวอักษรมั่วเหลือจากลายตกแต่งสองสามจุด Apple Vision อ่านบรรทัดนี้ถูกและไม่มีตัวมั่ว ถ้าต้องการแม่นกว่านี้ ขั้นต่อไปคือเปลี่ยนตัวตรวจบรรทัดเป็นของ PaddleOCR

การเผื่อขอบ 15% ของความสูงบรรทัดแก้ `แขวง` กับ `เขต` ที่เคยอ่านเป็น `แบวง` กับ `เบต` ได้ การกรองคะแนนต่ำกว่า 0.6 (และ 0.9 ถ้ามีตัวเดียว) ตัดตัวมั่วจากลายตกแต่งออกส่วนใหญ่

## ตัวเลือกที่ไม่ได้ใช้

| ตัวเลือก | ขนาด | ทำไมไม่ใช้ |
|---|---|---|
| Typhoon OCR 1.5 (2B) | 2B พารามิเตอร์ | ต้อง GPU หรือ Ollama ไม่มีพิกัดบรรทัด การ์ดเตือนว่าอาจแต่งข้อความ และอยู่ภายใต้ OpenTyphoon Terms and Conditions |
| Xiaomi-OCR-0 (0.8B) | ราว 1.8 GB | ไม่ระบุภาษาไทย ไม่ระบุพิกัด ไม่มีตัวเลขความเร็ว |
| Apple Vision | ไม่มีไฟล์ | ใช้ได้เฉพาะ Mac จึงใช้เป็นเกณฑ์เทียบเท่านั้น |

โมเดลใหญ่ไม่ได้ทำให้จบทีเดียว: ยังต้องมีตัวตรวจบรรทัด ยังอ่านผิดแบบแต่งขึ้นได้ และยังต้องมีตัวรันโมเดลเพิ่มกับไฟล์ระดับ GB

## ยังไม่ได้ทำ

แก้ข้อความที่ฝังในภาพยังทำไม่ได้ OCR ให้แค่ข้อความที่ค้นหาได้ ต้นแบบที่เคยลอง (ลบพิกเซลเดิมด้วยสีเรียบ แล้ววางข้อความใหม่) ยังไม่ได้ใส่ในแอป
